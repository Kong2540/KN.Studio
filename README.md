# KN-Studio — ชุดไฟล์แอป (PWA)

แอปออกแบบโครงสร้างบ้าน ค.ส.ล. ทำงานบน iPhone, iPad, มือถือ Samsung และ Android ทุกยี่ห้อ รวมถึงคอมพิวเตอร์
ติดตั้งเป็นไอคอนบนหน้าจอได้ และใช้งานได้แม้ไม่มีอินเทอร์เน็ต

## อุปกรณ์ที่รองรับ
- iPhone และ iPad: iOS / iPadOS 15.4 ขึ้นไป (ใช้ Safari ติดตั้ง)
- Android และ Samsung: Chrome 90 ขึ้นไป หรือ Samsung Internet 15 ขึ้นไป
- คอมพิวเตอร์: Chrome, Edge, Safari, Firefox รุ่นปัจจุบัน

## ขั้นที่ 1: อัปโหลดขึ้นเว็บไซต์ (ทำครั้งเดียว ฟรี)
แอปต้องเปิดจากเว็บไซต์ที่เป็น https จึงจะติดตั้งลงเครื่องได้ วิธีที่ง่ายที่สุด:

**Netlify Drop** (ใช้คอมพิวเตอร์)
1. แตกไฟล์ zip นี้ จะได้โฟลเดอร์ที่มี index.html อยู่ข้างใน
2. เปิด https://app.netlify.com/drop แล้วลากโฟลเดอร์นั้นวางลงในหน้าเว็บ
3. จะได้ลิงก์ เช่น https://ชื่อสุ่ม.netlify.app สมัครบัญชีฟรีเพื่อเก็บลิงก์ไว้ถาวรและเปลี่ยนชื่อได้

**GitHub Pages** (ทางเลือก)
1. สร้าง repository ใหม่ แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
2. Settings → Pages → เลือก branch main แล้วกด Save

เมื่อมีเวอร์ชันใหม่ ให้อัปโหลดทับที่เดิม แอปในเครื่องจะอัปเดตเองเมื่อเปิดครั้งถัดไปขณะมีอินเทอร์เน็ต

## ขั้นที่ 2: ติดตั้งลงเครื่อง
- **iPhone / iPad:** เปิดลิงก์ด้วย Safari → แตะปุ่มแชร์ → “เพิ่มไปยังหน้าจอโฮม”
- **Android / Samsung:** เปิดลิงก์ด้วย Chrome หรือ Samsung Internet → แตะปุ่ม “ติดตั้งแอป” ในหน้าโครงการ หรือเมนู ⋮ → “ติดตั้งแอป”
- **คอมพิวเตอร์:** กดไอคอนติดตั้งที่แถบที่อยู่ของ Chrome หรือ Edge

## ข้อมูลโครงการ
- โครงการเก็บในเครื่องที่ใช้งานเท่านั้น (IndexedDB) ไม่ส่งขึ้นอินเทอร์เน็ต
- กด “ส่งออกไฟล์” ในหน้าโครงการของฉัน เพื่อได้ไฟล์ .kns ไว้สำรองหรือส่งไปเปิดในเครื่องอื่นด้วย “นำเข้าไฟล์”
- บน iPhone / iPad ควรใช้แบบติดตั้งแล้ว เพราะ Safari อาจล้างข้อมูลของเว็บที่ไม่ได้เปิดนาน และควรส่งออกไฟล์สำรองเป็นระยะ

## โครงสร้างไฟล์
- index.html, manifest.webmanifest, sw.js — ตัวแอปและการทำงานออฟไลน์
- js/rules.js — ค่าจากกฎกระทรวง 2566 พร้อมแหล่งอ้างอิง
- js/core.js, js/store.js — ข้อมูลโครงการและที่เก็บในเครื่อง
- js/beam.js — เครื่องออกแบบคาน (ทดสอบเทียบไฟล์ P2160_ST.xlsx แผ่น B1)
- js/workbench.js — แปลนชั้นและภาพ 3D
- js/views.js, js/app.js — หน้าจอและการนำทาง
- vendor/three.min.js (r128), fonts/ — ไลบรารีและฟอนต์ที่เก็บไว้ในเครื่อง
